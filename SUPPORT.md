# Getting Support for DocuHarvest

Thank you for using DocuHarvest! Here are the best ways to get help, report issues, and discuss features.

---

## 1. Questions & Usage Help
If you have questions about:
- How to configure custom content selectors.
- How to tune rate limits or virtualized scroll depth for complex doc frameworks.
- Best practices for ingesting exported Markdown into AI frameworks (LangChain, LlamaIndex, Claude, Gemini, OpenAI).

Please use **[GitHub Discussions](https://github.com/Kalpesh-ops/DocuHarvest/discussions)**. This helps other users discover answers to common questions.

---

## 2. Reporting Bugs
If you believe you have discovered a bug in discovery, extraction, tab handling, or export formatting:
1. Check the [Existing Issues](https://github.com/Kalpesh-ops/DocuHarvest/issues) to verify it hasn't already been reported.
2. If not, open a new issue using our **[Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md)**.
3. Provide browser version, documentation platform (e.g., Docusaurus, Sphinx, custom React SPA), and reproduction steps.

---

## 3. Feature Suggestions
Have an idea for DocuHarvest? We welcome proposals for:
- Support for new documentation platforms or code block highlighters.
- Specialized vector embedding chunking strategies during export.
- Enhanced queue management and link discovery heuristics.

Please open a feature request using our **[Feature Request Template](.github/ISSUE_TEMPLATE/feature_request.md)**.

---

## 4. Security Vulnerabilities
Please do **NOT** post sensitive security vulnerabilities publicly. Follow the instructions in **[SECURITY.md](SECURITY.md)** to report issues privately to maintainers.
